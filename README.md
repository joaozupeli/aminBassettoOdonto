# Amin Bassetto Odontologia

Demo personalizado (Vue 3 + Vite + GSAP + Vue Router) — Capão Raso, Curitiba.

Tema **light boutique**: branco / neutros quentes + acentos dourados suaves.

## Rodar local

```bash
npm install
npm run dev
```

## Personalizar

Conteúdo em `src/data/clinic.js`. Tema em `src/style.css` (`:root` CSS variables).

## Deploy

`vercel.json` faz rewrite SPA. Projeto sugerido: `amin-bassetto-odonto`.
